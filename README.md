\# 🧠 MindBridge – AI Student Support Assistant



MindBridge is an AI-powered student support assistant designed to provide supportive, context-aware responses using Large Language Models.



\## Features



\- 🤖 AI-powered conversational support

\- 🧠 Context-aware responses

\- 💬 Interactive Streamlit chat interface

\- 🔗 LLM integration using Google Gemini

\- 🛡️ Environment-based API key management



\## Tech Stack



\- Python

\- Streamlit

\- Google Gemini API

\- LangChain

\- LLMs

\- python-dotenv
